# dustinmcguire.com
Static site (GitHub Pages). No build step.

- **Add a history entry:** edit `data/history.js` (copy a line, change it). Sorted automatically newest to oldest.
- **Publications:** hidden in `_hidden_publications/` (not published). See the README in that folder to enable it later.
- **Logos:** placeholders in `assets/logos/` - replace with real logos (same file names).
- **Nav/footer:** edit `site.js`. **Timeline/publication drawing:** `render.js`.
- **TODO markers:** search for "TODO" in `projects/` to fill in the gaps.
